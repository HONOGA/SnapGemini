專為手機打造的極速 AI 視覺分析工具！**點開就是鏡頭 ➔ 一按快門 ➔ 0 秒直達 Gemini 2.0 / 1.5 Flash 深度視覺分析**，省去傳統繁瑣的 5~7 個步驟。

## ✨ 核心特色

- 🚀 **1 鍵極速拍即問**：開啟即全螢幕取景，按下大快門自動截圖直通 Google 官方 Gemini API。
- 🔮 **6 大智慧預設模式**：
  - 🔍 **萬物解讀**：品種、品牌、地標、植物、物品由來與實用背景。
  - 📝 **文字提取 (OCR)**：條理化排版、表格整理與核心重點摘要。
  - 🌐 **翻成繁中**：外文看板、商品標籤、文件即拍即翻（繁體中文在地化）。
  - 💡 **解題解答**：試題解析、家電故障排查、錯誤訊息診斷。
  - 🍽️ **飲食熱量**：菜品辨識、熱量 (kcal) 預估、三大營養素比例分析。
  - 💬 **自訂提問**：支援文字或「語音輸入」自訂專屬問題。
- 🔊 **中文語音朗讀 (TTS)**：按下喇叭圖示或開啟「自動朗讀」，用聽的吸收分析結果！
- 💬 **多輪追問**：針對同一張照片直接在下方繼續對話追問。
- 🕒 **離線歷史紀錄**：拍攝過的紀錄自動保存在手機本地，隨時回顧。
- 🔒 **極致安全隱私**：API Key 僅存在手機本機（`localStorage`），手機直連 Google 官方，不經任何第三方伺服器。
- 📲 **PWA 原生級體驗**：支援加到 Android 桌面，全螢幕無網址列運行。

## 🚀 如何在手機上使用？

### 方式一：同 Wi-Fi 區域網路直接開給手機用（最快）

1. **在電腦上啟動伺服器**：
   ```bash
   npm start
   # 或 node server.js
   ```
2. **終端機會顯示手機專屬網址**，例如：
   ```text
   📱 手機同 Wi-Fi 訪問: http://192.168.1.100:3000
   ```
3. **在 Android 手機上打開 Chrome**，輸入上述網址。
4. **將它加到桌面（極速體驗關鍵）**：
   - 點擊 Chrome 右上角選單「`⋮`」
   - 選擇 **「加到主畫面 (Add to Home screen)」** 或 **「安裝應用程式」**
   - 之後只要在手機桌面上點開 `SnapGemini` 圖示，**一秒直接進相機**！

> 💡 **相機權限小提醒**：
> 部分 Android 瀏覽器若經由 `http://` 訪問局域網 IP，可能會限制相機硬體存取。若遇到相機無法開啟，可使用下方「免費雲端一鍵部署（自帶 HTTPS）」，體驗最完美！

---

### 方式二：免費部署到雲端（自帶 HTTPS，隨時隨地可用 ⭐ 推薦）

因為本專案是純前端無後端依賴的極速架構，您可以免費發布到：

1. **GitHub Pages**：將此專案推送到 GitHub Repository ➔ 開啟 Pages 即可。
2. **Cloudflare Pages / Vercel / Netlify**：直接把資料夾拖曳上傳，10 秒內生成專屬 `https://xxx.pages.dev` 網址。
3. 手機直接書籤收藏或「加到主畫面」，走到哪拍到哪！

## 🔑 API Key 設定方式

1. 打開網頁後，點擊右上角 **⚙️ 齒輪圖示**。
2. 貼上您的 **Gemini API Key**（可在 [Google AI Studio](https://aistudio.google.com/app/apikey) 免費取得）。
3. 選擇您偏好的模型（推薦預設 **Gemini 2.0 Flash**，速度極快又聰明）。
4. 點擊「儲存設定」即可開始暢快拍照！
